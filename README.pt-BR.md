## ![Godot Engine](https://img.shields.io/badge/godotengine-%23478CBF.svg?style=for-the-badge&logo=godotengine&logoColor=white) Projetos Godot (C#)

- [godot-supercon]: Um controlador de personagens flexível, configurável e extensível para jogos 2D e 3D em Godot.
- [godot-gdirector]: Um *addon* para Godot que provê uma solução completa para operar câmeras 3D com comportamento dinâmico, feito com jogabilidade e *cutscenes* em mente. Inspirado no pacote Cinemachine de Unity.
- [godot-polyshape-2d]: Um *addon* para Godot que adiciona o nó `Platform2D`, uma extensão do `Polygon2D` com bordas curvas, geração automática de formas de colisão e colocação automática de *sprites* em bordas, ideal para qualquer jogo 2D.
- [godot-animation-sprite-to-player]: Um *addon* para Godot que copia dados de animação de `AnimatedSprite2D` para `AnimationPlayer`.
- [godot-atlas-texture-importer]: Um *addon* para Godot que automatiza o processo de importação de texturas "atlas" criando recursos `AtlasTexture` a partir de arquivos atlas JSON.
- `gastorm` (em breve): Um *addon* para Godot que reimagina o sistema GAS do Unreal Engine para o ambiente Godot.
